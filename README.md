Razer's profile editor for the Tartarus V1 is no longer supported. That's fine, but afterwards it started locking up constantly so I vibe coded my own. It just changes the profile files you still need to restart the profile editor Razer provides in order for the changes to take. It's probably not great, I haven't really reviewed it BUT it works well enough so that I can keep using my Tartarus V1. Enjoy!
